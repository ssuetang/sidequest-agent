# Story Agent

Turns a persona, available time, budget, and shortlisted places into a chaptered SideQuest with prompts, micro-tasks, timing, and estimated costs.

## Sample queries

1. Build a 90-minute day as a 90s indie filmmaker in Greenwich Village.
2. I have three hours and want to see my city as a novelist.
3. Create a $25 museum time-traveler quest in Morningside Heights.
