# Adaptation Agent

Keeps an active SideQuest playable when plans change, repairing only affected stops while preserving the persona, timing, and theme.

## Sample queries

1. The gallery is closed and it's raining. Keep the novelist theme.
2. It looks like rain near my next stop. Adapt the route for indoors.
3. I only have 45 minutes left and do not want to walk more than 10 minutes.
